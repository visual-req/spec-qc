## Web UI ユーザーマニュアル

### 1) 起動とページへのアクセス

起動後にアクセスします：

- http://localhost:8765/

ページは3つのセクションに分かれています：

- 上部：設定とスキャンの開始
- 中部：スキャンサマリー（進捗リスト / ステータスログ）
- 下部：問題の確認（承認 / 拒否）

### 2) 操作方法の選択と設定（設定を展開）

設定エリアでは2つの操作方法をサポートしています：

- ローカルディレクトリ：ローカルの指定ディレクトリ内の `.doc/.docx` を直接スキャンします。
- ファイルのアップロード：ブラウザで複数の `.doc/.docx` を選択してアップロードし、スキャンします（出力はデフォルトの `work` ディレクトリに行われます）。

#### ローカルディレクトリ

レビュー対象要件ディレクトリ（`req_dir`）：

- 絶対パスを直接入力します（最も安定しています）。

要件レビュー結果ディレクトリ（`out_dir`、オプション）：

- 空白のまま：デフォルトで作業ディレクトリの `work/output` が使用されます。
- 絶対パスを入力：結果を指定したディレクトリに書き込みます。
- または、「フォルダの選択」をクリックして、ページ内でターゲットディレクトリを参照して選択することもできます（ローカルディレクトリモードにのみ影響します）。

ルールディレクトリ（`rules_dir`、オプション）：

- 絶対パスを直接入力します（ディレクトリ内に複数の `.md` ルールファイルを配置可能）。
- 空白のまま：デフォルトのルールディレクトリ `work/quality` が使用されます。

#### ファイルのアップロード

スキャンするファイルのアップロード：

- 「ファイルの選択」をクリックし、複数の `.doc/.docx` を一度に選択できます。
- 「クリア」をクリックすると、選択したファイルが削除されます。
- アップロードされたファイルはデフォルトの `work/input` に保存され、上書きを防ぐためにファイル名にタイムスタンプが追加されます。スキャンタスクは今回のアップロード用に `work/uploads` の下に隔離されたディレクトリを作成します。

このモードでは：

- ルールディレクトリはデフォルトの `work/quality` に固定されます。
- 出力ディレクトリはデフォルトの `work/output` に固定されます。

### 3) スキャンの開始

右上の「スキャンの開始」をクリックします：

- スキャンはファイルごとに進行し、ルールに従って分割してモデルにリクエストを送信します。
- ページは「スキャンサマリー」と「問題の確認」をリアルタイムで更新します。

### 4) スキャンサマリーとダウンロード

スキャンサマリーエリア：

- 「リストを展開」：各ファイルのステータス、ルール数、問題数、出力パスを表示します。
- 行をクリック：問題エリアをそのファイルに切り替え、集中的に処理しやすくします。
- 「ダウンロード」：そのファイルに対応するExcel結果をダウンロードします（1ファイルにつき1つの出力）。
- 「ログを展開」：現在のタスクのステータスログ（UI側で追加されたプロセス情報）を表示します。

### 5) 通知（新しい問題へのクイックジャンプ）

スキャン中に新しい問題が見つかった場合、右上の「通知」に数字のバッジが表示されます：

- 「通知」をクリック：問題リストを展開します。
- 通知をクリック：対応するファイルに自動的に切り替わり、その問題の位置に移動します（ハイライト表示）。

### 6) 問題の確認：承認 / 拒否

問題確認エリア：

- 「ファイルフィルタ」：特定のファイルを選択するか、「すべて」を選択します。
- 各問題には以下が含まれます：重要度、カテゴリ、ページ/セクション、内容の抜粋、提案。
- 「展開/折りたたむ」をクリックして詳細を表示します。

処理アクション：

- 「承認」：その問題を承認済みとしてマークし、改訂版Wordへの書き込みを試みます（成功した場合、改訂版のパスを返し、ステータスエリアにプロンプトを表示します）。
- 「拒否」：その問題を拒否済みとしてマークします。

### 7) ファイルの保存場所（デフォルト `work`）

デフォルトの作業ディレクトリを使用する場合：

- Excel：`work/output/*.xlsx`
- レビュー記録：`work/output/*.review.json`
- 改訂版Word：`work/revise/*.docx`
- ログ：`work/logs/spec-qc.log` および `work/logs/large-model.log`
