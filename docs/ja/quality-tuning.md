# 品質チューニング

![品質チューニング](../assets/quality-tuning.svg)

要点：

- ルール調整：ルール項目の分割/追加、業界ルールの追加により、誤検知や業界跨ぎの誤判定を減らす
- プロンプトとパラメータ：分割戦略、出力フォーマット制約、例と用語の整合により、一貫性と実行可能性を高める
- 閉ループ：スキャン結果 → 人手レビュー → ルール/プロンプト調整 → 再スキャンで検証

## 業界ルールの追加（推奨）

- `work/quality` 配下に業界ルールファイルを追加（例：`banking_quality_standard.md`）。ファイル冒頭で適用業界を宣言（例：`适用行业：银行/金融`）し、業界跨ぎの誤検知を防ぐ
- ルールは品質次元ごとにグルーピング（例：`####` を見出しに使用）。各ルールに「問題/反例/対策/効果/適用場面」を含めるとモデルの命中が安定する
- 追加/調整後は過去サンプル文書で回帰スキャンを実施し、「拒否理由 → ルール調整」のフィードバックループで継続的に改善する
