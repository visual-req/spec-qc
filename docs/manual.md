## Web UI 使用手册

### 1) 启动与进入页面

启动后访问：

- http://localhost:8765/

页面分为三块：

- 顶部：配置与开始扫描
- 中部：扫描汇总（进度列表/状态日志）
- 底部：问题查看（接受/拒绝）

### 2) 配置目录（展开配置）

待评审需求目录（req_dir）：

- 方式 A：直接填写绝对路径（本机运行最方便）
- 方式 B：点击“选择文件夹”并选择包含 `.docx` 的目录（浏览器会上传该文件夹内文件）

需求评审结果目录（out_dir，可选）：

- 留空：默认使用工作目录的 `work/output`
- 填写绝对路径：把结果写到指定目录
- 也可点击“选择文件夹”在页面内浏览并选中目标目录

规则目录（rules_dir，可选）：

- 方式 A：直接填写绝对路径（目录下可放多个 `.md` 规则文件）
- 方式 B：点击“选择文件夹”上传规则目录
- 留空：使用内置通用规则

### 3) 开始扫描

点击右上角“开始扫描”：

- 扫描会逐文件进行，并按规则分段请求模型
- 页面会实时刷新“扫描汇总”与“问题查看”

### 4) 扫描汇总与下载

扫描汇总区域：

- “展开列表”：显示每个文件的状态、规则数、问题数、输出路径
- 点击某一行：会把问题区切到该文件，便于集中处理
- “下载”：下载该文件对应的 Excel 结果（每个文件一个输出）
- “展开日志”：显示本次任务的状态日志（UI 侧追加的过程信息）

### 5) 问题确认：接受 / 拒绝

问题查看区域：

- “文件筛选”：选择某个文件，或选择“全部”
- 每条问题包含：严重程度、分类、页号/章节、内容摘录、建议
- 点击“展开/折叠”查看详情

处理动作：

- “接受”：把该问题标记为已接受，并尝试写入修订版 Word（若成功会返回修订版路径并在状态区提示）
- “拒绝”：把该问题标记为已拒绝

### 6) 文件落盘位置（默认 work）

如果使用默认工作目录：

- Excel：`work/output/*.xlsx`
- 审核记录：`work/output/*.review.json`
- 修订版 Word：`work/revise/*.docx`
- 日志：`work/logs/spec-qc.log` 与 `work/logs/large-model.log`
