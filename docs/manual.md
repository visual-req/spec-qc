## Web UI 使用手册

### 1) 启动与进入页面

启动后访问：

- http://localhost:8765/

页面分为三块：

- 顶部：配置与开始扫描
- 中部：扫描汇总（进度列表/状态日志）
- 底部：问题查看（接受/拒绝）

### 2) 选择操作方式与配置（展开配置）

配置区支持两种操作方式：

- 本机目录：直接扫描本机某个目录内的 `.doc/.docx`
- 上传文件：在浏览器内选择多个 `.doc/.docx` 上传后扫描（输出使用默认 work 目录）

#### 本机目录

待评审需求目录（req_dir）：

- 直接填写绝对路径（最稳定）

需求评审结果目录（out_dir，可选）：

- 留空：默认使用工作目录的 `work/output`
- 填写绝对路径：把结果写到指定目录
- 也可点击“选择文件夹”在页面内浏览并选中目标目录（仅影响本机目录模式）

规则目录（rules_dir，可选）：

- 直接填写绝对路径（目录下可放多个 `.md` 规则文件）
- 留空：使用默认规则目录 `work/quality`

#### 上传文件

上传待扫描文件：

- 点击“选择文件”，一次可选择多个 `.doc/.docx`
- 点击“清空”可移除已选择文件
- 上传后的文件会落到默认 `work/input`，文件名会追加时间戳避免覆盖；扫描任务会在 `work/uploads` 下为本次上传建立隔离目录

该模式下：

- 规则目录固定使用默认 `work/quality`
- 输出目录固定使用默认 `work/output`

### 3) 开始扫描

点击右上角“开始扫描”：

- 扫描会逐文件进行，并按规则分段请求模型
- 页面会实时刷新“扫描汇总”与“问题查看”

### 4) 扫描汇总与下载

扫描汇总区域：

- “展开列表”：显示每个文件的状态、规则数、问题数、输出路径
- 点击某一行：会把问题区切到该文件，便于集中处理
- “下载”：下载该文件对应的 Excel 结果（每个文件一个输出）
- “展开日志”：显示本次任务的状态日志（UI 侧追加的过程信息）

### 5) 提醒（新问题快捷跳转）

扫描过程中，如果发现新的问题，右上角“提醒”会出现数字角标：

- 点击“提醒”：展开问题列表
- 点击某条提醒：自动切换到对应文件，并定位到该条问题（高亮显示）

### 6) 问题确认：接受 / 拒绝

问题查看区域：

- “文件筛选”：选择某个文件，或选择“全部”
- 每条问题包含：严重程度、分类、页号/章节、内容摘录、建议
- 点击“展开/折叠”查看详情

处理动作：

- “接受”：把该问题标记为已接受，并尝试写入修订版 Word（若成功会返回修订版路径并在状态区提示）
- “拒绝”：把该问题标记为已拒绝

### 7) 文件落盘位置（默认 work）

如果使用默认工作目录：

- Excel：`work/output/*.xlsx`
- 审核记录：`work/output/*.review.json`
- 修订版 Word：`work/revise/*.docx`
- 日志：`work/logs/spec-qc.log` 与 `work/logs/large-model.log`
